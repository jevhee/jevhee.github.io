# Jevi Saputra - Personal Portfolio

A minimalist, high-performance personal portfolio website built with modern web technologies.

## 🛠 Tech Stack

- **Vanilla JavaScript**: Lightweight, module-based components (ES Modules) without the overhead of heavy UI frameworks.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI styling, customized exclusively with the [Catppuccin](https://catppuccin.com/) color palette.
- **Vite**: Next-generation frontend tooling for blazing-fast local development and highly optimized, minified production builds.
- **Husky & lint-staged**: Automated Git pre-commit hooks to ensure code quality.
- **Prettier**: Opinionated code formatter to maintain consistent code style across HTML, JS, and CSS.
- **GitHub Actions**: Automated CI/CD pipeline for building and deploying directly to GitHub Pages.

## 🚀 Getting Started

### Prerequisites

Make sure you have [Bun](https://bun.sh/) installed.

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   bun install
   ```

### Development

Start the Vite development server with Hot Module Replacement (HMR):

```bash
bun run dev
```

### Production Build

Create an optimized production build in the `dist/` folder:

```bash
bun run build
```
