# Technical Specification (SPEC)

## 1. Tech Stack
- **Core:** Semantic HTML5
- **Styling:** Tailwind CSS (via CDN) to exactly match the design and spacing generated by Stitch.
- **Interactivity:** Vanilla JavaScript (ES6+) for theme toggling and micro-interactions.
- **Hosting/Deployment:** GitHub Pages (Static Site).

## 2. Architecture & File Structure
Since the site will be hosted on GitHub Pages and relies on Tailwind CSS CDN with a custom config, the file structure will be streamlined:

```
/
├── index.html       # Main entry point containing Tailwind classes and custom config script
├── scripts/
│   └── theme.js     # Dark/Light mode toggle logic + localStorage
└── assets/          # Fonts, icons, images
```
*(Note: We will no longer need complex standalone CSS files for layout and components, as Tailwind utility classes handle this directly in HTML).*

## 3. Theming Engine (Tailwind Config)
To implement the Catppuccin Macchiato (Dark) and Latte (Light) themes seamlessly:
- We will configure Tailwind's `tailwind.config` to include custom Catppuccin colors.
- We will utilize Tailwind's `darkMode: "class"` feature.
- **Theme Switcher:** JavaScript will listen for clicks on the theme toggle button, toggle the `dark` class on the `<html>` tag, and save the preference in `localStorage`.

## 4. Typography Integration
- **Geist (Sans-serif):** Headings and body copy.
- **JetBrains Mono (Monospace):** Tags, badges, and technical accents.
- Both fonts will be imported via Google Fonts or standard CDN in the `<head>` of `index.html`.

## 5. Deployment Pipeline (GitHub Pages)
- No build step is required due to the CDN usage of Tailwind. 
- The site can be deployed directly from the `main` branch to GitHub Pages.
